# Stuntbaan Duel

Een 3D stuntracer voor in de browser: gas en rem, kantelen in de lucht, loopings, schansen en ravijnen.
Speel alleen tegen de computer of met maximaal vier spelers tegen elkaar, elk op een eigen toestel.

**Spelen:** https://lpompen.github.io/stuntbaan-duel/

- Tegen elkaar: de eerste speler kiest *Race hosten* en geeft de code van vier letters door; de anderen vullen die in en kiezen *Meedoen*.
- Met punten uit races en stunts speel je nieuwe auto's vrij. Punten en auto's blijven op je eigen toestel staan.
- Telefoon of tablet: houd het toestel liggend. Toetsenbord: pijltjes of A/D.

Deze repository bevat alleen de gepubliceerde spelbestanden (v3.0.0).
